ACTCSS1: Internal CSS Styling

<!DOCTYPE html>
<html>
<head>
<style>
#para1 { text-align: center; color: red; }
</style>
</head>
<body>

<p id="para1">Hello! This is Gab's Website</p>
<p>This paragraph is not affected by the style.</p>

</body>
</html>

Hello! This is Gab's Website

This paragraph is not affected by the style.

ACTCSS2: Center-Aligned Text with Class

<!DOCTYPE html>
<html>
<head>
<style>
.center {
text-align: center;
color: black;
}
</style>
</head>
<body>

<h1 class="center">black and center-aligned heading</h1>
<p class="center">black and center-aligned paragraph.</p>

</body>
</html>

black and center-aligned heading

black and center-aligned paragraph.

ACTCSS3: Paragraph with Class Selector

<!DOCTYPE html>
<html>
<head>
<style>
p.center {
text-align: center;
color: green;
}
</style>
</head>
<body>

<h1 class="center">This heading will not be affected</h1>
<p class="center">This paragraph will be green and center-aligned.</p>

</body>
</html>

This heading will not be affected

This paragraph will be green and center-aligned.

ACTCSS4: Combining Classes for Styling

<!DOCTYPE html>
<html>
<head>
<style>
p.center {
text-align: center;
color: green;
}
p.large {
font-size: 250%;
}
</style>
</head>
<body>

<h1 class="center">This heading will not be affected</h1>
<p class="center">This paragraph will be green and center-aligned.</p>
<p class="center large">This paragraph will be green, center-aligned, and in a medium font-size.</p>

</body>
</html>

This heading will not be affected

This paragraph will be green and center-aligned.

This paragraph will be green, center-aligned, and in a medium font-size.
